# Pasta Public

Coloque aqui seus arquivos estáticos que devem ser servidos diretamente na raiz da aplicação (ex: logos, favicons, fontes, imagens públicas).

### Exemplo de uso:
Se você colocar `logo.png` aqui, no seu código você pode usar direto:
```tsx
<img src="/logo.png" alt="Logo Cajuí" />
```
